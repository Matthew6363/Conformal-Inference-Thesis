# Conformal-Inference-Thesis

In this work we analysed the use of Conformal Inference (a good paper explaining what we mean by that is: https://arxiv.org/pdf/2107.07511 from Angelopoulos and Bates)

A great task in Machine Learning is to produce predictions but how confident are we in the results? Here we use this framework to produce predictions and, at the same time, confidence intervals in order to give an uncertainty estimate over the results.
